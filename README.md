# LLM Engineering Portfolio

Hands-on projects from revising Ed Donner's *LLM Engineering: Master AI and Large Language Models* course. Each week has its own small, real-world project that applies that week's theory. Built in Python, running on free local models with [Ollama](https://ollama.com) wherever possible.

I'm a mobile developer (Flutter, React Native, Android) building toward AI engineering: Python AI backends that power mobile apps.

## Setup

Requirements: Python 3.12, [uv](https://docs.astral.sh/uv/) and [Ollama](https://ollama.com).

```bash
git clone https://github.com/Moeez189/llm-engineering-portfolio.git
cd llm-engineering-portfolio
uv sync
```

Each project folder has its own README with instructions, design decisions and what I learned.
